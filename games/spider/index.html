Game Center

How to play

Goal: untangle two full decks (104 cards) across ten columns and build eight complete King-to-Ace runs in one suit.

The layout

  • Tableau: ten columns; the first four start with 6 cards, the rest with 5.
  • Stock (top-right): click to deal one extra row — a card to every column.
  • Runs (top-left): every finished K→A suit is collected here. Collect all 8 to win.

Moving cards

  • Build down by rank in any suit, but you can only lift a run of the same suit.
  • Drag & drop a card or run onto a card one rank higher, or into an empty column.
  • Double-click a card to send it to the best column that fits.
  • Uncovered face-down cards flip up automatically.

Drawing

  • Dealing requires no empty columns — fill them first.
  • The stock holds 5 deals; the last one is usually the tricky one.

Extras

  • 1 / 2 / 4 suits changes difficulty — one suit is a calm weave, four is a brawl.
  • Score starts at 500, −1 per move, +100 per completed suit.
  • Shortcuts: N new · U undo · H hint · Space deal · R rules.

Your game is saved automatically — refresh any time and the web picks up where you left it.
